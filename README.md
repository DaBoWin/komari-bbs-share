# MJJBOX论坛Komari探针监控 使用教程

一个为MJJBOX论坛用户设计的Tampermonkey脚本，可以在论坛中分享展示Komari探针的服务器统计信息。

## 🚀 快速开始

### 1. 安装脚本
1. 确保已安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 复制 `komari-monitor.user.js` 脚本内容
3. 在Tampermonkey中创建新脚本并粘贴代码
4. 保存并启用脚本

### 2. 基础配置
1. 访问 [mjjbox.com](https://mjjbox.com) 论坛
2. 点击页面右下角的 ⚙️ 配置按钮
3. 填写以下信息：
   - **论坛用户名**：你在MJJ论坛的用户名
   - **探针域名**：你的Komari探针地址（如：`https://probe.example.com`）
   - **探针API Key**：可选，如果探针需要认证
   - **共享时显示域名**：勾选后其他用户可以看到你的探针域名

### 3. 测试连接
点击"测试连接"按钮验证探针配置是否正确。

## 📊 功能特性

### 探针按钮
- 配置完成后，你的用户名旁会出现 📊 探针 按钮
- 点击按钮可查看详细的服务器统计信息

### 统计信息包括
- **节点状态**：在线节点数量和百分比
- **系统状态**：CPU使用率、系统负载
- **资源使用**：内存、交换分区、硬盘使用情况
- **网络统计**：流量统计、实时速度、连接数

### 共享功能
- **分享探针**：保存配置时自动分享到社区
- **查看他人探针**：查看其他用户分享的探针信息
- **隐私控制**：可选择是否向他人显示探针域名

## 🔧 配置选项

| 选项 | 说明 | 必填 |
|------|------|------|
| 论坛用户名 | MJJ论坛的用户名 | ✅ |
| 探针域名 | Komari探针的完整URL | ✅ |
| 探针API Key | 探针认证密钥 | ❌ |
| 共享时显示域名 | 控制域名对他人的可见性 | ❌ |

## 🛠️ 管理功能

### 配置界面按钮
- **保存配置**：保存设置并自动分享
- **测试连接**：验证探针连接
- **刷新共享**：更新共享探针列表
- **查看共享**：浏览社区探针

### 隐私设置
- 取消勾选"共享时显示域名"可隐藏你的探针域名
- 其他用户将无法看到你的具体探针地址
- 但仍可查看你的服务器统计信息

## 📱 使用场景

1. **个人监控**：随时查看自己服务器状态
2. **社区分享**：与论坛朋友分享服务器信息
3. **性能对比**：查看其他用户的服务器配置
4. **故障排查**：快速检查服务器运行状态

## ⚠️ 注意事项

- 脚本仅在 mjjbox.com 域名下工作
- 需要Komari探针支持RPC2接口
- 共享功能需要网络连接
- 建议定期刷新共享列表获取最新数据
